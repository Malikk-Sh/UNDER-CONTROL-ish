Under Control-ish

Всё под контролем!

Кооперативный 2D-платформер для браузера и мобильных устройств. От одного до восьми работников чинят, носят и запускают оборудование в опасном комплексе — задачи сами подстраиваются под состав бригады.

Игре нужен запущенный сервер, поэтому играть прямо отсюда нельзя. Запуск локально:

npm install
npm run dev

Дальше откройте http://localhost:5173.

  • Свободное независимое движение, без тросов и обязательных пар
  • Авторитетный сервер, предсказание и интерполяция на клиенте
  • Вся графика и звук генерируются в рантайме — внешних ассетов нет
  • Деплой одним web service на render.com

Подробности — в README и в техническом GDD.
